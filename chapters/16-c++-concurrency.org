
* C++ Concurrency

** Concurrency Basics

- Large application have multiple components
- Some components may have to execute concurrently
- This allows efficient usage of the CPU
- This can be achievd by creating multiple threads
- C++11 added support for concurrency
- Threding library includes utilities for starting and managing threads

#+LATEX: \captionof{listing}{Single Thread Application}

** std::thread

- Accepts a callable as constructor argument
- The callable is executed in a seperate thread
- The constructor does not wait for the thread to start it returns
  immediately.
- Resides in <thread> header

** Task Based Concurrency - Part II

*** std::async
- Part of high-level concurrency
- Executes a /callable/ object of a function in a seperate thread
- Returns a /std::future/ objec that provides access to the result of
  the callable
- Include the header /<future>/

  /future<return_type> async (Callable, args)/
  /future<return_type> async(launch policy, Callable, args)/

*** Launch Policy
  - /std::launch::deferred/ - the task is executed synchronously
  - /std::launch::async/ - the task is executed asynchronoulsy

- Call to /std::async/ without a launch policy may not always create a
  new thread
  - depends on the compiler implementation
  - To force /std:async/ to execute the task asynchronoulsy, use the
    async lauch policy explicittly

- If new thread cannot be created with async launch policy,
  /std::system_error/ exception is thrown

*** Task Arguments & Return Value
- Arguments can be specified in /std::async/ for the task
- By default, the arguments are passed by value
- To pass by reference, use the reference wrapper, /std::ref/
  - for constant reference, use /std::cref/
- To get a value from a task, simply return it from the corresponding function
- This value is than availble throuhg the future object
*** std::future
- Used for communication between threads
- Has a *shared state* that can be accessed in a different thread
- Create through a /std::promise/ object
  - created by /std::async/, that directly returns a future object
  - /std::promise/ is an *input* channel
  - /std::future/ is the *output* channel
- The thread that reads the shared state will wait until the future is
  ready (with the shared state)
- Promise/future pair allow safe data sharing between threads

** std::promise

- Provides a way to store a value or an exception
- This is called the *shared state*
- This state can be accessed later from another thread through a
  /future/ object
- /promise/future/ are two *endpoints of a communication channel
- One operation stores a value in a /promise/ and the other operation
  will retrieve it through a /future/ *asynchronoulsy*
- These operations are *synchronized*, therefore *thread-safe*
- /promise/ object can be used only once


#+LATEX: \captionof{listing}{Promise - Future}
#+BEGIN_SRC C++ :exports both :flags "-std=c++17 -pthread -Wall -Wextra -fno-elide-constructors" :results output verbatim
#include <iostream>
#include <future>
#include <thread>

using namespace std;
using namespace chrono_literals;

int Operation(std::promise<int>& data) {
    auto f = data.get_future();                 // get future
    cout <<"[task] waiting for count" << endl;
    auto count = f.get();                       // get data
    int sum {};
    for (int i = 0; i < count; ++i) {
        sum += i;
        cout << '.';
        this_thread::sleep_for(300ms);
    }
    return sum;
}

int main() {

    for(int i = 0; i < 3; ++i) {
        promise<int> data;

        this_thread::sleep_for(100ms);
        cout << "[main] Setting the data in promise: ";  
        data.set_value(10+i);           // set data
        if(result.valid()) {

            auto sum = result.get();            
            cout << "Sum: " << sum << endl;   // simiöar to jon
        }
        cout << '\n';
    }
    return 0;
}

int Operation(std::promise<int>& data) {

        throw runtime_error{"Counter failed"};
        cout << "[task] waiting for count" << endl;

        for (int i = 0; i < count; ++i) {

#include <iostream>
#include <future>
#include <thread>

using namespace std;
using namespace chrono_literals;

int Operation(std::promise<int>& data) {
    auto f = data.get_future();                     // get future
    try {
        throw runtime_error{"Counter failed"};
        cout << "[task] waiting for count" << endl;
        auto count = f.get();                        // get data
        int sum {};
        for (int i = 0; i < count; ++i) {
            sum += i;
            cout << '.' ;
            this_thread::sleep_for(300ms);
        }
        return sum;
    }
    catch(exception &ex) {
        // no exception pointer needed to propaget from task to main
        cout << "[task] Exception: " << ex.what() << endl;
        return -1;
    }
}

int main() {

    promise<int> data;
    future<int> result = async(launch::async, Operation, std::ref(data));
    this_thread::sleep_for(100ms);
    cout << "[main] Setting the data in promise: " << endl;;  
    try {
        throw runtime_error{"Data not available"};
        data.set_value(10);           // set data
        if(result.valid()) {
            auto sum = result.get();            
            cout << "Sum: " << sum << endl;   // simiöar to jon
        }
        cout << '\n';
    }catch(exception &ex) {
        data.set_exception(make_exception_ptr(ex)); // Exception Pointer 
        cout << "[main] Exception: " << ex.what();
    }

}
