** Introduction

- Heart of the standard library for C++
- Developed by Alexander Stepnov & Meng Lee at Hewlett Packard
- Provides fas & reusable *containers* and *algorithms*
- Relies heavily on templates; almost every component in the STL is a
  template.

*Core Components*
- *Container* classes, *algorithms* & *iterators* form the core components of the STL
- Container classes represent data & algorithms represent operations on the data
- Iterators serve as the *glue* between containers and algorithms
- Also include classes for *concurrency*, *random numbers*, *regular expressions*, *utilities*, etc.


*Why use the STL*
- Quicker development
- Reliable
- Portable
- Efficient & fast
- Accurate
- Readable code
- Lower maintenance cost
