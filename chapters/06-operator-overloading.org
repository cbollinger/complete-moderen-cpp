* Operator Overloading

** Operator Overloading - Part I-III
- Custom implementation for primitive operators
- Allow usage of user-defined objects in mathematical expression
- Overloaded as functions but provide a convenient notation
- Implemented as member or global functions
- Require usage of the operator keyword

  /<ret> operator <#> (<arguments>)/

- As global functions, require same no. of arguments as the operands
- As member functions, one operand is passed as argument through this pointer
  - binary operator will require only one explicit argument
  - unary operator will not require any explicit argument

   /Integer operator+(const Integer &, const Integer &);/
   /Integer Integer::operator+(const Integer &);/

    ++(*m_pInt);
    return *this;  // the value a the address of this

    cout << "operator++(int)" << endl;
    Integer temp(*this);
    ++(*m_pInt);
    return temp;

bool Integer::operator==(const Integer & a) const { // c==a means c.operator==(a)
    cout << "operator==(const Integer &) const" << endl;
    return *m_pInt == *a.m_pInt;
}

Integer & Integer::operator=(const Integer & a) { // c=a means c.operator=(a)
    cout << "operator=(const Integer &) const" << endl;
    if (this != &a) {            // check for self assignemnt
    delete m_pInt;
    m_pInt = new int(*a.m_pInt);
    }
    return *this;
}

Integer & Integer::operator=(Integer && a) { // c=&&a means c.operator=(&&a)
    cout << "operator=(Integer &&) const" << endl;
    if (this != &a) {
    delete m_pInt;
    m_pInt = a.m_pInt;
    a.m_pInt = nullptr;
    }
    return *this;
}

Integer Integer::operator+(const Integer & a) const { // c+a means c.operator+(a)
    cout << "operator+(const Integer &) const" << endl;
    Integer temp;
    *temp.m_pInt = *m_pInt + *a.m_pInt; // *this->m_pInt
    return temp;
}

// ------------------------------------------------------------------------
// Integer Class Declaration
// ------------------------------------------------------------------------
class Integer {
    int *m_pInt;
public:
    Integer();                                  // Default constructor
    Integer(int value);                         // Parameterized constructor
    Integer(const Integer &obj);                // Copy constructor
    Integer(Integer &&obj);                     // Move constructor
    int GetValue()const;
    void SetValue(int value);
    ~Integer();
    Integer & operator ++();                    // pre-increment operator
    Integer operator ++(int);                   // post-increment operator
    bool operator ==(const Integer &a)const;    // comparison
    Integer & operator =(const Integer &a);     // Copy assignment
    Integer & operator =(Integer &&a);          // Move assignment
    Integer operator +(const Integer & a)const; // + operator

    void operator ()();                         // Function Call Operator

    // operator >> is friend of Class Integer
    friend std::istream & operator >> (std::istream &input, Integer &a);
}

// ------------------------------------------------------------------------
// Global Function Declarations
// ------------------------------------------------------------------------
Integer operator +(int x, const Integer &y);
std::ostream & operator <<(std::ostream & out, const Integer &a);
std::istream & operator >> (std::istream &input, Integer &a);

// -------------------------------------------------------------------------
// Global Function Definition (operator>>() overloading)
// ------------------------------------------------------------------------
std::istream & operator >> (std::istream &input, Integer &a) {
    int x;
    input >> x;
    // a.SetValue(x);  // SetValue() allows copy by value, no friend required
    ,*a.m_pInt = x;     // access to private member of Integer Class.   
    return input;
}

** Operator Overloading - Part VII (Rules)
- Associativity, precedence & arity (operand count) does not change
- Operator functions should be *non-static*
  - except for new & delete
- One argument shold be *user defined* type
- *Global* overload if first operand is primitive type
- Not all operators can be overloaded
  - . ?: .* sizeof
- Cannot define new operators
- Overload for conventional behaviour only
  

** Type Conversions - Part I (Basics)
- Conversions between types
- Performed through casts
- Ordered by compiler *(implicit)* or user *(explicit)*
- Conversion between
  - basic & basic
  - basic & user defined
  - user defined & basic
  - user defined & user defined

#+LATEX: \captionof{listing}{Type conversion examples}
#+BEGIN_SRC C++ :exports both :padline no :flags "-std=c++17 -Wall -Wextra -fno-elide-constructors" :results output verbatim

    float f1 = a/b;                     // result is 2 because
                                        // division of 2 integer gives also an integer

    float f2 = (float) a/b;             // c-style cast - no check for validness of cast
    cout << "f2= " << f2 << endl;

    // char *p2 = static_cast<char *>(&a);    // syntaxs not ok - not compilable
