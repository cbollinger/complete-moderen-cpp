** Required Software 

You can choose any of the following compilers & Integrated Development
Environments. In this training, we’ll use Visual Studio 2015/2017/2019
Community edition. The same programs can be compiled without any
changes in any *C++11/14/17* compliant compiler on any platform.

*** Windows

- Visual Studio 2015/2017/2019  [[https://www.visualstudio.com/vs/community/]] NOTE: PREFER THE LATEST VERSION OF VISUAL STUDIO
- Code::Blocks - requires a separate compiler [[https://www.codeblocks.org/]]
- Cevelop - requires a separate compiler [[https://www.cevelop.com/]]
- Eclipse CDT - requires a separate compiler (same as Cevelop) [[https://eclipse.org/cdt/downloads.php]]
- MinGW [[http://mingw.org/]]
- Visual Studio Code [[https://code.visualstudio.com/]]

*** Linux (Ubuntu, CentOS, etc)

- GNU C++ Compiler (Install from command line e.g. sudo apt-get install g++)
- Cevelop [[https://www.cevelop.org/]]
- Eclipse CDT (same as Cevelop) [[https://eclipse.org/cdt/downloads.php]]

*** MacOS

- XCode (Install from Mac Appstore)
- Cevelop [[https://www.cevelop.com/]]
- Eclipse CDT (same as Cevelop) [[https://eclipse.org/cdt/downloads.php]]
