** Access Modifiers

#+ATTR_LATEX:  :align p{5cm}l
| <40>      | <40>                                           |
| *modifier*  | *Meaning*                                        |
|-----------+------------------------------------------------|
| private   | Inaccessible outside the class                 |
| public    | Accesible outside the class                    |
| protected | Accessible only to class and its child classes |


#+ATTR_LATEX:  :align p{5cm}p{5cm}l
| <40>               | <40>                      |                             |
| *Class Base*       | *Class Child : public Base* |                             |
|--------------------+---------------------------+-----------------------------|
| private: MemberA   | private: MemberA          | not accessible in the Child |
| public: MemberB    | public: MemberB           | accessilbe                  |
| protected: MemberC | protected: MemberC        | accessible                  |



#+ATTR_LATEX:  :align p{5cm}p{5cm}l
| <40>               | <40>                      |                             |
| *Class Base*       | *Class Child : private Base* |                             |
|--------------------+---------------------------+-----------------------------|
| private: MemberA   | private: MemberA          | not accessible in the Child |
| public: MemberB    | private: MemberB          | accessible                  |
| protected: MemberC | private: MemberC          | accessible                  |


#+ATTR_LATEX:  :align p{5cm}p{5cm}l
| <40>               | <40>                      |                             |
| *Class Base*       | *Class Child : protected Base* |                             |
|--------------------+---------------------------+-----------------------------|
| private: MemberA   | private: MemberA          | not accessible in the Child |
| public: MemberB    | protected: MemberB        | accessible                  |
| protected: MemberC | protected: MemberC        | accessible                  |

If no modifier is used for inheritance than the default modifier is used:
- /public/ if the child is structure
- /private/ if the child is a class
independant wheather the base is a struct or a class.

*Object Construction*
- Constructors execute from base to child
- Destructors execute from child to base
- Base data members will be part of child object

** Project - VI (Virtual Mechanism Internals I)

*Polymorphism*
- Different forms of the function are provided
- The call is resloved at compile time or runtime
- /Runtime polymorphism/ or /dynamic binding/
- Implemented through virtual mechanism
- Compiler inserts code to invoke the correct function at *runtime*
- Automatically generated through the *virtual keyword*
- Such functions are called *polymorphic functions*
- Should be invoked only through a pointer or a reference

*Vtable*
- Array of function pointers called as *virtual table*
- contains addresses of the virtual functions

*Vptr*
- Virtual poiner member of the class (automatically generated)
- Points to the Vtable of the corresponding class
- The *Vptr* is inherited and points to the *Vtable* of the inherited class

*Object Slicing*
- A Situation in which the compiler deliberately removes some part of an object
- Occurs when a child class object is assigned to a concrete base class object
- The size of a child class object may be more than its base class
- While assigning it to a base object, some part of the memory may get overwritten
- This will lead to *memory corruption*
- To *prevent* this, the *compiler slices* the child object, effectively
  removing the memory that conatains it attributes
- The object is then copied into the base object.

#+ATTR_LATEX: :options {RTTI}
#+BEGIN_infobox
During compile time, the compiler creates the type information of the
object as a type_info object, and that is stored with the class vtable at runtime.

When we use type id or dynamic cast, these operators will query that
information. So RTTI will impose overhead on the program, especially dynamic_cast.

*Avoid RTTI* instead rely on polymorphism so that the corect behaviour
is invoked polymorphic without having to know the type of the object.
#+END_infobox


** Abstract Class and pure virtual Functions

*pure virtual Function*
- /virtual void Serialize(float version) = 0/
- /= 0/ is know as the *pure specifier*
- does not have an implementation (optional)
- cannot be invoked (except by derived classes if defined)
- no entry in the *vtable*
- must be overriden by the derived classes
- if it is not overriden the child class becomes also a pure virtual function

*Abstract Class*
- has at least *one pure virtual function*
- can contain other members
- can *not be instantiated*, but used through a pointer or reference
- Establishes a contract with clients
- Used for creating *interfaces*
