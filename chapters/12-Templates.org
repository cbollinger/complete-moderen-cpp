
* Templates


** Introduction to Templates

- Generalizes software components
- Such components can be reused in different situations
- Operate of any kind of data
- High performance algorithm & classes
- Compile time; no run time costs are involved
- Libraries such as ATL, WTL, Boost, POCO, ACE, etc. use templates for implementation

** Template Argument Deduction & Instantiation

*Template Argument Deduction:*
- Process of decucing the types
- Each function argument is examined
- The corresponding type argument is deduced from the argument
- The type argument deduction should lead to same type
- Type conversion are not performed
- After deduction, the templae is instantiated
- Override deduction by specifying types in template argument list
  /Max<int>(3,5);/

*Template Instantiation:*
- A template function of class only acts as a *blueprint*
- The compiler generates code from the blueprint at *compile time*
- Know as template instantiation
- Occurs implicitly when
  - a function template is invoked
  - taking address of a function template
  - using explicit instantiation
  - creating explicit specialization
- Full definition of template shoulb be available
- Define in *header-file*

** Non-type Template Arguments

- Expression that is computed at compile time within a template argument list
- Must be a constant expression (addresses,references,integrals,nullptr,enums)
- Part of the template library
- Used to implement std::begin & std::end functions

            m_Buffer[i] = obj.m_Buffer[i];

** Type Traits (C++11)


- C++ does not have any support for introspection at runtime, C++11
  introduced tpye traits
- Tpye traits give the ability to introspect

- Will either return a boolean or a type when inspecting types
- Provides template-based interface and defined in header /<type_traits>/
- Some traits require support from the compiler

** static_assert (C++11)

- /static_assert/ is a new kind of declaration for evaluating expressions
